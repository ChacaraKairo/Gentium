# Changelog

## 1.0.0 — Primeira versão estável

- Bíblia offline com PorBLivre, WEB para comparação e textos originais.
- Organização pessoal com favoritos, anotações, marcações, tags e coleções.
- Ferramentas acadêmicas iniciais com Strong, léxico e interlinear por token.
- Sistema de estudos offline com cursos, módulos, lições e progresso.
- Planos de leitura offline com leitura diária, progresso, estatísticas e histórico.
- Biblioteca avançada offline com comentários, dicionário, referências cruzadas, paralelos, mapas, cronologias e genealogias.
- Diagnóstico local de pacotes offline.
- Backup local em JSON via compartilhamento nativo.
- Validação de release com TypeScript, seeds, traduções, documentação e metadados de versão.
