# Requisitos Funcionais

Versão: 1.0

Autor: Kairo Chácara

---

# 1. Introdução

Este documento descreve todos os requisitos funcionais do Gentium.

Os requisitos funcionais representam as funcionalidades que deverão ser implementadas na plataforma, servindo como base para o desenvolvimento, testes e evolução do sistema.

Cada requisito recebe um identificador único para facilitar sua rastreabilidade.

---

# 2. Leitura da Bíblia

## RF-001

O sistema deverá permitir a leitura completa da Bíblia.

## RF-002

O usuário deverá navegar entre livros, capítulos e versículos.

## RF-003

O sistema deverá lembrar automaticamente a última leitura realizada.

## RF-004

O usuário poderá alterar a versão da Bíblia disponível.

## RF-005

O sistema deverá funcionar completamente offline.

## RF-006

O usuário poderá ajustar tamanho da fonte.

## RF-007

O usuário poderá alterar o espaçamento entre linhas.

## RF-008

O usuário poderá alternar entre modo claro e escuro.
