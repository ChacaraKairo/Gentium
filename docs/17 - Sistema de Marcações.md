# Sistema de Marcações

**Versão:** 1.0
**Autor:** Kairo Chácara

---

# 1. Introdução

O Sistema de Marcações do Gentium permite destacar trechos das Escrituras de forma organizada e personalizada.

Seu objetivo é auxiliar o usuário na identificação rápida de versículos importantes, facilitando revisões, estudos temáticos e consultas futuras.

As marcações funcionarão completamente offline e serão integradas aos demais módulos da plataforma.

---

# 2. Objetivos

O sistema deverá permitir:

- Destacar versículos.
- Utilizar múltiplas cores.
- Criar categorias personalizadas.
- Organizar marcações.
- Pesquisar marcações.
- Relacionar marcações com estudos.
- Sincronizar marcações entre dispositivos.

---

# 3. Filosofia

Cada usuário possui uma forma própria de estudar a Bíblia.

O Gentium não imporá um único método de marcação.

Cada pessoa poderá criar seu próprio sistema de cores, categorias e significados.

---

# 4. Estrutura da Marcação

Cada marcação poderá conter:

- Cor.
- Nome.
- Categoria.
- Observação.
- Data de criação.
- Última alteração.
- Autor.
- Status de sincronização.

---

# 5. Tipos de Marcação

## Marcação Simples

Destaca um único versículo.

---

## Marcação Contínua

Permite selecionar um intervalo de versículos.

Exemplo:

Romanos 8:28–39.

---

## Marcação por Palavra

Permite destacar apenas uma palavra ou expressão dentro do versículo.

Exemplo:

"Graça"

em Efésios 2:8.

---

## Marcação Temática

Relaciona diversos versículos ao mesmo tema.

Exemplo:

Tema:

Salvação

Versículos:

- João 3:16
- Romanos 10:9
- Efésios 2:8-9

---

# 6. Sistema de Cores

O usuário poderá utilizar cores padrão ou criar novas.

Exemplo:

Amarelo

- Promessas.

Verde

- Esperança.

Azul

- Doutrina.

Vermelho

- Salvação.

Roxo

- Profecias.

Laranja

- Evangelismo.

Cada cor poderá receber um significado personalizado.

---

# 7. Categorias

As marcações poderão ser agrupadas em categorias.

Exemplos:

- Estudos.
- Escola Bíblica.
- Pregações.
- Devocional.
- Família.
- Liderança.
- Missões.

---

# 8. Etiquetas

Além das categorias, será possível utilizar etiquetas.

Exemplos:

- Fé.
- Graça.
- Amor.
- Justiça.
- Reino.
- Arrependimento.

Uma marcação poderá possuir diversas etiquetas.

---

# 9. Pesquisa

O sistema permitirá pesquisar marcações por:

- Cor.
- Categoria.
- Etiqueta.
- Livro.
- Capítulo.
- Versículo.
- Palavra.
- Data.

A pesquisa funcionará totalmente offline.

---

# 10. Observações

Cada marcação poderá possuir uma observação rápida.

Exemplo:

"Utilizar este texto na aula de domingo."

As observações poderão ser editadas posteriormente.

---

# 11. Integração com Anotações

Uma marcação poderá possuir uma ou mais anotações vinculadas.

Fluxo:

```text
Versículo

↓

Marcar

↓

Adicionar Observação

↓

Criar Anotação Completa (opcional)
```

---

# 12. Integração com Estudos

As marcações poderão ser utilizadas dentro de estudos.

Exemplo:

Estudo:

O Sermão do Monte

↓

Todos os versículos destacados serão exibidos automaticamente.

---

# 13. Favoritos

Uma marcação poderá ser favoritada.

Isso permitirá acesso rápido às marcações mais importantes.

---

# 14. Histórico

O sistema registrará:

- Data da criação.
- Última edição.
- Última sincronização.

---

# 15. Compartilhamento

O usuário poderá compartilhar:

- Apenas o versículo.
- O versículo com a marcação.
- O versículo com observações.
- A referência bíblica.

O compartilhamento nunca alterará os dados armazenados no aplicativo.

---

# 16. Exportação

Será possível exportar marcações.

Formatos previstos:

- PDF.
- Markdown.
- JSON.
- Texto.

---

# 17. Importação

O usuário poderá importar marcações previamente exportadas.

Durante a importação deverão ser preservados:

- Cor.
- Categoria.
- Etiquetas.
- Observações.
- Datas.

---

# 18. Sincronização

As marcações poderão ser sincronizadas entre dispositivos.

A sincronização deverá preservar:

- Cores.
- Categorias.
- Etiquetas.
- Observações.
- Favoritos.

---

# 19. Inteligência Artificial

A IA poderá auxiliar sugerindo:

- Temas comuns entre marcações.
- Organização por assunto.
- Agrupamentos automáticos.
- Estudos relacionados.
- Revisões recomendadas.

Essas sugestões dependerão da autorização do usuário.

---

# 20. Desempenho

O sistema deverá suportar milhares de marcações sem perda perceptível de desempenho.

Todas as pesquisas deverão permanecer rápidas mesmo com grande volume de dados.

---

# 21. Recursos Futuros

O Sistema de Marcações poderá incorporar:

- Gradientes de cores.
- Ícones personalizados.
- Símbolos.
- Desenhos sobre o texto.
- Marcação por camada.
- Marcação compartilhada entre grupos.
- Filtros inteligentes.
- Estatísticas de uso.

---

# 22. Integração

O Sistema de Marcações será integrado aos seguintes módulos:

- Bíblia.
- Estudos.
- Anotações.
- Favoritos.
- Pesquisa.
- IA.
- Planos de leitura.
- Gamificação.

---

# 23. Experiência do Usuário

Criar uma marcação deverá exigir poucos passos.

Fluxo sugerido:

```text
Selecionar versículo

↓

Escolher cor

↓

Salvar
```

Caso deseje, o usuário poderá adicionar categoria, etiqueta e observação posteriormente.

---

# 24. Considerações Finais

O Sistema de Marcações foi projetado para permitir que cada usuário desenvolva seu próprio método de estudo das Escrituras.

Ao oferecer liberdade para personalização, organização e integração com os demais módulos do Gentium, as marcações deixam de ser apenas destaques visuais e passam a fazer parte da construção do conhecimento bíblico ao longo da vida.

Todo o sistema deverá funcionar offline, preservar os dados do usuário e evoluir de forma compatível com futuras funcionalidades, como sincronização, inteligência artificial e cursos bíblicos.
