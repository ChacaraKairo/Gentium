# UI e UX

Versão: 1.0

Autor: Kairo Chácara

---

# 1. Introdução

Este documento estabelece as diretrizes de Interface do Usuário (UI) e Experiência do Usuário (UX) do Gentium.

O objetivo é proporcionar uma experiência intuitiva, organizada e agradável, permitindo que qualquer pessoa utilize o aplicativo independentemente de seu nível de conhecimento bíblico ou experiência com tecnologia.

Todas as decisões relacionadas à interface deverão seguir os princípios definidos neste documento.

---

# 2. Objetivos

A interface deverá:

- Ser simples.
- Ser intuitiva.
- Exigir poucos toques.
- Reduzir distrações.
- Facilitar a leitura.
- Facilitar o estudo.
- Incentivar o retorno diário.
- Tornar a navegação previsível.

---

# 3. Princípios da Experiência

A experiência do usuário deverá transmitir:

- Paz.
- Organização.
- Clareza.
- Confiança.
- Continuidade.
- Simplicidade.

O aplicativo deverá evitar excesso de informações em uma única tela.

---

# 4. Público

A interface deverá atender usuários com diferentes níveis de conhecimento.

Perfis:

- Iniciante.
- Intermediário.
- Avançado.
- Professor.
- Pastor.
- Pesquisador.

Os recursos avançados deverão aparecer de forma gradual.

---

# 5. Navegação

A navegação deverá ser simples e consistente.

O usuário nunca deverá se sentir perdido.

Todas as telas deverão possuir:

- Título.
- Botão de retorno quando necessário.
- Caminho lógico.
- Feedback das ações.

---

# 6. Página Inicial

A tela inicial deverá apresentar acesso rápido às principais funcionalidades.

Prioridade sugerida:

- Continuar leitura.
- Apoiar o Gentium.
- Bíblia.
- Estudos.
- Planos de leitura.
- Anotações.
- Favoritos.
- Pesquisa.
- Configurações.

O usuário deverá conseguir iniciar uma leitura em poucos segundos.

---

# 7. Leitura da Bíblia

A tela de leitura deverá priorizar o texto bíblico.

Elementos secundários deverão permanecer discretos.

Durante a leitura, o usuário deverá conseguir:

- Alterar versão.
- Alterar fonte.
- Alterar tema.
- Marcar versículos.
- Criar anotações.
- Compartilhar referências.
- Copiar texto.
- Abrir estudos relacionados.

---

# 8. Estudos

Os estudos deverão possuir estrutura semelhante a capítulos de um curso.

Cada estudo deverá conter:

- Introdução.
- Conteúdo.
- Referências bíblicas.
- Resumo.
- Próximos passos.

---

# 9. Anotações

Criar uma anotação deverá exigir o menor número possível de etapas.

As anotações deverão ser organizadas por:

- Tema.
- Livro bíblico.
- Data.
- Etiquetas.

---

# 10. Pesquisa

A pesquisa deverá aceitar:

- Palavra.
- Frase.
- Referência bíblica.
- Livro.
- Capítulo.
- Versículo.

Os resultados deverão ser rápidos e organizados.

---

# 11. Feedback Visual

Toda ação do usuário deverá produzir uma resposta clara.

Exemplos:

- Salvamento.
- Exclusão.
- Erro.
- Carregamento.
- Sincronização.

---

# 12. Estados da Interface

Todos os componentes deverão possuir estados definidos.

Exemplos:

- Carregando.
- Vazio.
- Erro.
- Sucesso.
- Offline.

Nenhuma tela deverá ficar sem tratamento para esses estados.

---

# 13. Acessibilidade

O Gentium deverá atender usuários com diferentes necessidades.

Recursos previstos:

- Ajuste da fonte.
- Alto contraste.
- Modo escuro.
- Compatibilidade com leitores de tela.
- Botões grandes.
- Boa área de toque.

---

# 14. Desempenho Percebido

Mesmo durante operações demoradas, o usuário deverá perceber que o sistema continua funcionando.

Estratégias:

- Skeleton Loading.
- Indicadores de progresso.
- Atualizações em segundo plano.

---

# 15. Experiência Offline

O usuário deverá perceber que o aplicativo funciona normalmente mesmo sem internet.

Sempre que possível:

- Não exibir erros de conexão.
- Explicar quais recursos dependem da internet.
- Continuar permitindo o estudo.

---

# 16. Notificações

As notificações deverão incentivar o estudo sem se tornarem invasivas.

Exemplos:

- Lembrete de leitura.
- Continuação do plano.
- Missões diárias.
- Novos estudos.

O usuário poderá desativar qualquer notificação.

---

# 17. Gamificação

A gamificação deverá incentivar aprendizado, nunca gerar ansiedade.

Princípios:

- Sem punições.
- Sem pressão excessiva.
- Recompensas por consistência.
- Evolução gradual.
- Objetivos claros.

---

# 18. Doações

A área de doações deverá transmitir transparência.

O usuário deverá compreender:

- Como o projeto é financiado.
- Para onde os recursos são destinados.
- Como cancelar uma assinatura.
- Que a doação é totalmente voluntária.

As funcionalidades essenciais do Gentium nunca dependerão de pagamento.

---

# 19. Inteligência Artificial

A IA deverá funcionar como assistente.

Nunca deverá substituir:

- O texto bíblico.
- O estudo pessoal.
- A interpretação do usuário.

As respostas deverão indicar claramente quando forem produzidas pela IA.

---

# 20. Evolução da Experiência

A interface deverá acompanhar o crescimento do usuário.

Conforme ele utilizar mais recursos, novas funcionalidades poderão ser sugeridas naturalmente, evitando sobrecarregar iniciantes.

---

# 21. Consistência

Todos os módulos deverão manter:

- Mesmo padrão visual.
- Mesmo comportamento.
- Mesma linguagem.
- Mesmos componentes.
- Mesmas animações.

---

# 22. Considerações Finais

A experiência do usuário é um dos pilares do Gentium.

Cada tela deverá ser projetada para aproximar o usuário do estudo das Escrituras, reduzindo distrações e facilitando a organização do conhecimento.

A interface deverá permanecer simples para quem está começando e suficientemente poderosa para atender usuários avançados, mantendo sempre o foco no aprendizado contínuo e na leitura da Palavra de Deus.
