# v0.6.0 — Sistema de Estudos

## Implementado

- Schema offline para áreas, categorias, cursos, módulos, lições e referências bíblicas.
- Progresso local de curso iniciado, lições concluídas e curso concluído.
- Seed inicial da biblioteca de estudos com cursos introdutórios.
- Tela `Estudos` navegável por área, categoria, curso, módulo e lição.
- Ação para iniciar curso.
- Ação para concluir lição e atualizar progresso.
- Referências bíblicas exibidas como ações dentro das lições.
- Traduções PT-BR e EN-US para a biblioteca de estudos.
- Validação `validate-v06.js` cobrindo seed de estudos e chaves de interface.

## Como validar

```bash
npm install
npm test
npx expo install --check
npm start -- --host localhost --clear
```

Fluxos manuais:

- Abrir `Estudos` e conferir a lista de áreas.
- Entrar em `Introdução à Bíblia`.
- Abrir a categoria `Fundamentos`.
- Abrir o curso `Como Estudar a Bíblia`.
- Iniciar o curso, abrir uma lição e concluir.
- Voltar ao curso e conferir o progresso atualizado.

## Pendências da versão

- Navegação direta da referência bíblica para a aba Bíblia.
- Biblioteca maior de cursos e lições.
- Estudos totalmente pesquisáveis.
- Revisões e exercícios.
- Recursos multimídia offline.
