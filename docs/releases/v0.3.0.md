# v0.3.0 — Organização Pessoal

## Implementado

- Sistema inicial de anotações offline.
- Editor simples para anotação livre.
- Criação de anotação vinculada a versículo na tela Bíblia.
- Sistema inicial de marcações por cor em versículos.
- Categorias iniciais para anotações e marcações.
- Tags por texto separado por vírgulas.
- Coleções iniciais de favoritos com coleção padrão e criação de novas coleções.
- Lista de anotações, marcações e coleções na aba Anotações.
- Exportação local básica em JSON via compartilhamento nativo.
- Atribuição da licença da `PorBLivre` na tela Mais.
- Correção do startup para exibir erro e permitir retry.
- Seed bíblico ajustado para preservar dados do usuário em futuras reimportações.
- Teste básico de integridade do pacote bíblico e chaves i18n.

## Como validar

```bash
npm install
npm test
npx expo install --check
npm start -- --host localhost --clear
```

Fluxos manuais:

- Abrir `Bíblia`, escolher um livro, capítulo e versículo.
- Criar uma anotação em um versículo.
- Marcar um versículo com uma cor.
- Favoritar um versículo.
- Abrir `Anotações` e conferir notas, marcações, coleções e exportação JSON.
- Criar uma anotação livre e uma coleção.

## Pendências da versão

- Editor rico de anotações.
- Edição e exclusão completas de notas, marcações, categorias, tags e coleções.
- Associação manual de favoritos a coleções específicas.
