# v1.1.0 — Expansão Bíblica

## Implementado

- Busca bíblica avançada com filtragem enquanto digita.
- Busca por livro, referência parcial, referência exata e texto do versículo.
- Busca sem acento para termos em português, como `joao` e `graca`.
- Escopo de busca entre `Toda a Bíblia` e `Capítulo atual`.
- Resultados tocáveis com indicação de tipo de correspondência.
- Seleção da tradução principal na leitura.
- Comparação automática com a outra versão offline disponível.
- Última leitura preserva a tradução selecionada.
- `versionCode` Android atualizado para `2`.
- `buildNumber` iOS atualizado para `2`.
- Validação `validate-v11.js` cobrindo busca avançada, seletor de tradução e metadados da release.

## Como Validar

```bash
npm install
npm test
npx expo install --check
npm start -- --host localhost --clear
```

Fluxos manuais:

- Abrir `Bíblia`.
- Digitar `joao` e conferir resultados de livro/referência.
- Digitar `João 3` e abrir um resultado.
- Digitar `graca` e conferir resultados por texto.
- Abrir um capítulo e alternar o escopo para `Capítulo atual`.
- Alternar a tradução entre `PorBLivre` e `WEB`.
- Ativar `Comparar` e conferir a versão complementar.
