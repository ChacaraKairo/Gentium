# v0.7.0 — Planos de Leitura

## Implementado

- Schema offline para planos, dias, leituras e progresso.
- Seed inicial com planos oficiais `7 Dias em João` e `5 Dias de Oração`.
- Nova aba `Planos`.
- Biblioteca de planos com duração, tempo médio diário e progresso.
- Tela de detalhes do plano.
- Ação para iniciar plano.
- Leitura do dia.
- Ação para concluir leitura diária.
- Estatísticas básicas com dias concluídos, pendentes e sequência.
- Histórico de dias do plano.
- Traduções PT-BR e EN-US.
- Validação `validate-v07.js` cobrindo seed de planos e chaves da interface.

## Como validar

```bash
npm install
npm test
npx expo install --check
npm start -- --host localhost --clear
```

Fluxos manuais:

- Abrir `Planos`.
- Abrir `7 Dias em João`.
- Iniciar o plano.
- Abrir a leitura do dia.
- Concluir a leitura.
- Voltar ao plano e conferir progresso, estatísticas e histórico.
