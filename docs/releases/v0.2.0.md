# v0.2.0 — Bíblia Offline Inicial

## Implementado

- Estrutura SQLite inicial para Bíblia offline:
  - `bible_versions`
  - `bible_books`
  - `bible_chapters`
  - `bible_verses`
  - `favorites`
  - `reading_history`
- Seed offline completo com `PorBLivre` importado do projeto `scrollmapper/bible_databases`.
- Navegação na aba Bíblia por livros, capítulos e versículos.
- Tela de leitura com texto bíblico como foco principal.
- Persistência de última leitura.
- Continuação da última leitura pela aba Bíblia e atalho na Home.
- Favoritar/remover favorito em versículos.
- Lista simples de favoritos dentro da aba Bíblia.
- Pesquisa offline por referência no formato `João 3:16`.
- Compartilhamento de versículo via API nativa do React Native.
- UI baseada no UI Kit e tokens existentes.

## Como validar

```bash
npm install
npm run typecheck
npx expo install --check
npm start -- --host localhost --clear
```

Fluxos manuais:

- Abrir `Bíblia`.
- Selecionar `Genesis`, `Psalms` ou `John`.
- Abrir um capítulo.
- Favoritar um versículo e voltar para ver a lista de favoritos.
- Pesquisar `John 3:16`.
- Compartilhar um versículo.
- Voltar à Home e tocar em `Continuar leitura`.
