# v0.1.0 — Fundação do Projeto

## Implementado

- Projeto Expo SDK 54 com React Native e TypeScript, compatível com Expo Go 54.
- Estrutura modular inicial conforme `docs/08 - Estrutura de Pastas.md`.
- Navegação principal por abas: Início, Bíblia, Estudos, Anotações e Mais.
- Tema claro e escuro baseado nos tokens do Design System.
- UI Kit inicial com texto, card, botões, botão de ícone, item de lista e layout de tela.
- Configuração inicial de SQLite com controle de migrações.
- Internacionalização inicial com `pt-BR` e `en-US`.
- Telas principais vazias para preservar o escopo da fundação.

## Como validar

```bash
npm install
npm run typecheck
npm start
```

O aplicativo deve abrir e permitir a navegação entre as abas principais.

## Pendências da versão

- Validação visual em dispositivo/emulador após instalação das dependências.
- Criação de ícones finais do aplicativo em `assets/images`.
- Testes automatizados iniciais para componentes e navegação.
