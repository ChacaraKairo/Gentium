# v1.0.0 — Primeira Versão Estável

## Implementado

- Versão do aplicativo atualizada para `1.0.0`.
- `versionCode` Android definido como `1`.
- `buildNumber` iOS definido como `1`.
- Backup local em JSON para dados pessoais e progresso.
- Changelog consolidado em `CHANGELOG.md`.
- Diagnóstico estável de pacotes offline mantido na tela `Mais`.
- Validação `validate-v10.js` cobrindo versão estável, changelog, release note, seeds, traduções e metadados de loja.

## Escopo Estável

- Bíblia offline.
- Pesquisa por referência.
- Favoritos.
- Anotações.
- Marcações.
- Estudos básicos.
- Planos básicos.
- Biblioteca avançada inicial.
- Idiomas originais e ferramentas acadêmicas iniciais.
- Backup local.
- Tema claro e escuro automático.
- Internacionalização PT-BR e EN-US.

## Como Validar

```bash
npm install
npm test
npx expo install --check
npm start -- --host localhost --clear
```

Fluxos manuais:

- Abrir o aplicativo com banco limpo.
- Navegar por todas as abas principais.
- Abrir Bíblia e pesquisar uma referência.
- Criar anotação, marcação e favorito.
- Iniciar estudo e concluir lição.
- Iniciar plano e concluir leitura.
- Abrir Biblioteca e buscar `João 3:16`.
- Abrir `Mais`, conferir diagnóstico e exportar backup JSON.
