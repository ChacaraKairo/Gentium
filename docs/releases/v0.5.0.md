# v0.5.0 — Ferramentas Acadêmicas

## Implementado

- Seed offline do léxico Strong a partir dos recursos locais do Bible SuperSearch.
- Tabela local `strong_lexicon` com raiz, transliteração, pronúncia, morfologia quando disponível e definição.
- Busca por número Strong, palavra original normalizada ou transliteração.
- Interlinear inicial por token do texto original.
- Painel de palavra original ao tocar em um item interlinear.
- Vinculação automática de palavras originais ao léxico Strong quando a forma normalizada encontra correspondência local.
- Traduções PT-BR e EN-US para as ferramentas acadêmicas.
- Validação `validate-v05.js` cobrindo sementes bíblicas, idiomas originais, léxico Strong e chaves de interface.

## Como validar

```bash
npm install
npm test
npx expo install --check
npm start -- --host localhost --clear
```

Fluxos manuais:

- Abrir `Bíblia`, escolher Gênesis 1 e alternar para `Original`.
- Tocar em uma palavra original e conferir o painel com transliteração e Strong quando houver vínculo.
- Buscar `H7225` no painel de ferramentas acadêmicas.
- Abrir João 3 e buscar `G25` ou uma transliteração grega.
- Alternar para `Comparar` e confirmar que o interlinear continua disponível junto da WEB.
