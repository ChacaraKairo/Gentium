# v0.4.0 — Idiomas Originais

## Implementado

- Seed offline de textos originais com WLC para Antigo Testamento e Textus Receptus para Novo Testamento.
- Identificação de trechos em aramaico bíblico em Esdras, Daniel e Jeremias.
- Tabela local para versões e versículos de idiomas originais.
- Transliteração local para hebraico, aramaico e grego.
- Seed offline da WEB para comparação com a PorBLivre.
- Modo de leitura por tradução, original e comparação.
- Exibição de original + transliteração ao lado da tradução.
- Manifesto de bancos bíblicos em `database/bible/manifest.json`.
- Documentação local dos pacotes SQLite e recursos Strong adicionados em `database/bible`.

## Como validar

```bash
npm install
npm test
npx expo install --check
npm start -- --host localhost --clear
```

Fluxos manuais:

- Abrir `Bíblia`, escolher Gênesis 1 e alternar para `Original`.
- Conferir o texto hebraico WLC e a transliteração abaixo da PorBLivre.
- Abrir Mateus 1 e conferir o texto grego TR.
- Abrir Daniel 2 e conferir a identificação de aramaico bíblico.
- Alternar para `Comparar` e conferir o texto WEB junto da tradução principal.
