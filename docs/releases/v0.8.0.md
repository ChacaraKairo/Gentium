# v0.8.0 — Biblioteca Avançada

## Implementado

- Schema offline para comentários bíblicos, dicionário bíblico, referências cruzadas, paralelos dos Evangelhos, mapas, cronologias e genealogias.
- Seed inicial da biblioteca avançada com recursos vinculados a referências bíblicas.
- Nova aba `Biblioteca`.
- Lista de seções da biblioteca com contagem de recursos.
- Visualização dos recursos por seção.
- Busca por referência bíblica para encontrar materiais auxiliares relacionados ao texto.
- Traduções PT-BR e EN-US.
- Validação `validate-v08.js` cobrindo seed da biblioteca avançada e chaves da interface.

## Como validar

```bash
npm install
npm test
npx expo install --check
npm start -- --host localhost --clear
```

Fluxos manuais:

- Abrir `Biblioteca`.
- Entrar em `Comentários bíblicos`.
- Voltar e abrir `Dicionário bíblico`.
- Buscar `João 3:16` no campo de referência.
- Conferir comentário e referência cruzada vinculados.
- Abrir mapas, cronologias e genealogias.
