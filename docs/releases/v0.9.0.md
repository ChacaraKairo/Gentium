# v0.9.0 — Beta Fechado

## Implementado

- Versão do aplicativo atualizada para `0.9.0`.
- Diagnóstico beta local na tela `Mais`.
- Checklist de pacotes offline carregados:
  - livros e versículos bíblicos;
  - idiomas originais;
  - léxico Strong;
  - lições de estudo;
  - dias de planos de leitura;
  - pacote da biblioteca avançada.
- Rótulos acessíveis melhores para itens de lista acionáveis.
- Validação `validate-v09.js` cobrindo versão, release note, seeds, chaves de interface e diagnóstico beta.
- Checagem Expo mantida como validação de compatibilidade de dependências.

## Como validar

```bash
npm install
npm test
npx expo install --check
npm start -- --host localhost --clear
```

Fluxos manuais:

- Abrir `Mais`.
- Conferir `Beta fechado v0.9.0`.
- Confirmar contagens dos pacotes offline.
- Navegar pelas abas principais.
- Abrir Bíblia, Estudos, Planos e Biblioteca.

## Pendências da versão

- Teste em dispositivo físico com banco limpo.
- Revisão visual em telas pequenas.
- Checklist manual de acessibilidade com leitor de tela.
- Correções de feedback do beta fechado.
